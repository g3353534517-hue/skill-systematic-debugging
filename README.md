# Systematic Debugging / 系统化调试方法论

![分类](https://img.shields.io/badge/分类-开发-blue)

## 项目简介

系统化调试的方法论技能。改问题的第一原则：先找出问题，不找出问题不行动。

看到现象 → 定位根因 → 确认机制 → 再动手修。不跳步。

## 调试流程

1. 观察现象：错误信息、异常行为、日志输出
2. 复现问题：稳定复现是最关键一步
3. 缩小范围：二分法排除无关因素
4. 定位根因：找到导致现象的最底层原因
5. 确认机制：理解为什么会导致这个问题
6. 修复验证：修后必须验证，且验证原场景和关联场景

## 核心原则

- 不猜测，用事实说话
- 每步只改一个变量
- 记录每步操作和结果
- 修一个bug不能引入新bug
